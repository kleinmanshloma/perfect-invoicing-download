# Perfect Invoicing for Windows and Mac

**What it is:** the installer files of Perfect Invoicing, the invoicing and cash register program for shops (<https://perfectinvoicing.com>). Installer files only.

**Windows:** download [Perfect-Invoicing-Setup.exe](https://github.com/kleinmanshloma/perfect-invoicing-download/releases/latest/download/Perfect-Invoicing-Setup.exe) and open it. If Windows says "Windows protected your PC", click **More info → Run anyway**. The program installs itself and opens; sign in as always.

**Mac (Apple chip and Intel):** download [Perfect-Invoicing.dmg](https://github.com/kleinmanshloma/perfect-invoicing-download/releases/latest/download/Perfect-Invoicing.dmg), open it and drag **Perfect Invoicing** onto **Applications**. The first time: **System Settings → Privacy & Security → Open Anyway**. Sign in as always.
